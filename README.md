# 🚀 Flash Delivery

**Flash Delivery** é uma aplicação web inspirada no Zé Delivery, focada em pedidos de bebidas com controle administrativo. O projeto foi desenvolvido como parte prática da graduação em Sistemas de Informação na PUCPR, apresentado para a turma e o professor **Cleverson**. Ao final, recebeu o **prêmio de melhor projeto da turma**.

## 🧠 Funcionalidades

- ✅ Autenticação com **JWT**
- ✅ **Proteção de rotas** por nível de acesso (usuário comum ou admin)
- ✅ CRUD completo de:
  - Produtos
  - Categorias
  - Usuários
- ✅ Sistema de **pedidos** com histórico salvo no banco de dados
- ✅ Cardápio **acessível somente a usuários logados**
- ✅ Interface 100% responsiva
- ✅ Todos os modelos 3D (latas, animações) criados no **Blender**
